# Data Formats

## config.json

```json
{
  "targetFunctions": ["osal_printk", "printk", "printf"],
  "filePatterns": ["*.c", "*.h"],
  "excludePatterns": ["node_modules/**", "dist/**", "*.test.*"]
}
```

| Field | Type | Description |
|-------|------|-------------|
| targetFunctions | `string[]` | Print function names to extract string literals from |
| filePatterns | `string[]` | File glob patterns to include |
| excludePatterns | `string[]` | File glob patterns to exclude (supports `**`) |

## paths.json

Supports string or object entries per path:

```json
{
  "paths": [
    "./src",
    {"path": "./drivers", "gitRepo": "/home/user/project-a"}
  ]
}
```

| Format | Fields | Description |
|--------|--------|-------------|
| String | - | Analysis path; git repo auto-detected by walking up for `.git` |
| Object | path, gitRepo | `gitRepo` is optional; auto-detected if omitted |

Each extracted item inherits its path's `gitRepo`.

## extracted.json

```json
{
  "version": "1.0",
  "generatedAt": "2026-04-22T10:00:00Z",
  "stats": { "total": 150, "pending": 120, "completed": 30 },
  "items": [
    {
      "id": "call-001",
      "functionName": "osal_printk",
      "filePath": "src/main.c",
      "gitRepo": "/home/user/project",
      "lineStart": 42,
      "lineEnd": 42,
      "columnStart": 5,
      "columnEnd": 40,
      "code": "osal_printk(\"hello\\n\");",
      "stringLiteral": "\"hello\\n\"",
      "stringLiteralOffsetStart": 1024,
      "stringLiteralOffsetEnd": 1032,
      "context": "...",
      "status": "pending",
      "batchId": null,
      "optimizedAt": null,
      "notes": ""
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| id | Unique identifier, e.g. `call-001` |
| functionName | The print function name |
| filePath | Relative file path |
| gitRepo | Associated git repo path |
| lineStart / lineEnd | Call site line numbers (1-based) |
| columnStart / columnEnd | Call site column numbers (1-based) |
| code | Full function call expression |
| stringLiteral | The first string argument with quotes (e.g. `"hello\n"`) |
| stringLiteralOffsetStart | Character offset of string literal start in file |
| stringLiteralOffsetEnd | Character offset of string literal end in file |
| context | Surrounding code (3 lines before/after) |
| status | `pending` or `completed` |
| batchId | Batch ID assigned by `get` |
| optimizedAt | ISO 8601 timestamp when marked done |
| notes | Optional notes |

## replacements.json

Generated by AI after optimizing strings. Consumed by the `apply` command.

```json
{
  "version": "1.0",
  "replacements": [
    {
      "id": "call-001",
      "replacement": "\"optimized hello\\n\""
    },
    {
      "id": "call-002",
      "replacement": "\"another optimized string\\n\""
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| id | Matches the `id` in `extracted.json` |
| replacement | New string literal including quotes (e.g. `"new string\n"`) |

The `apply` command verifies the original `stringLiteral` still exists at the recorded offset before replacing.
